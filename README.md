# Кинотека

Личный кинотеатр: один каталог на все фильмы, сериалы и шоу, своя библиотека
файлов, скачивание и никакой рекламы. Интерфейс сделан в первую очередь под
**телевизор** (пульт, 10-футовый UI, слабое железо) и во вторую — под **планшет
и телефон**.

## Что это такое

Три вещи в одном месте:

| | |
|---|---|
| **Каталог** | Практически любой фильм, сериал и шоу — с русскими названиями, описаниями, постерами, трейлерами и актёрами. Данные берутся из [TMDB](https://www.themoviedb.org). |
| **Своя библиотека** | Ваши файлы (папка, NAS, внешний диск) индексируются, получают обложки и играют прямо в сайте: русская дорожка, 4K, HDR, субтитры, скачивание. |
| **Где смотреть легально** | Для того, чего нет у вас на полке, показывается сервис, у которого есть права в вашей стране — Кинопоиск, Okko, Wink, START, Иви. Один клик из каталога. |

> Кинотека не раздаёт чужой контент и не подключается к пиратским балансерам.
> Играет то, что лежит у вас; для остального даёт быстрый путь в лицензионный
> сервис.

## Быстрый старт

```bash
git clone <репозиторий> kinoteka && cd kinoteka
npm install
cp .env.example .env
```

Откройте `.env` и заполните минимум два поля:

```ini
TMDB_API_KEY=ваш_ключ          # бесплатно: themoviedb.org/settings/api
MEDIA_ROOTS=/mnt/movies,/mnt/series
ACCESS_CODE=придумайте_код     # его вы дадите друзьям
```

Соберите клиент и запустите:

```bash
npm run build
npm start
```

Готово — `http://<ip-машины>:8080`. На телевизоре откройте этот адрес во
встроенном браузере; на iPad — «Поделиться» → «На экран Домой», приложение
запустится в полный экран.

## Файлы

Кинотека понимает то, как люди на самом деле называют файлы:

```
Brother.1997.2160p.BDRemux.HDR.RUS.DTS-HD.mkv
Интерстеллар (2014) 1080p BluRay RUS ENG.mp4
Сериалы/Wednesday/Season 1/Wednesday.S01E01.1080p.WEB-DL.RUS.mkv
```

Из имени вытаскиваются название, год, сезон и серия, разрешение, HDR, источник
и языки дорожек. Субтитры рядом с видео (`фильм.ru.srt`) подхватываются
автоматически и на лету конвертируются в WebVTT.

Установите **ffmpeg** — тогда вместо догадок по имени читается сам контейнер:
реальные аудиодорожки, их языки и встроенные субтитры.

```bash
sudo apt install ffmpeg        # Debian/Ubuntu
brew install ffmpeg            # macOS
```

Пересканировать вручную:

```bash
npm run scan            # только новые и изменённые файлы
npm run scan -- --force # перечитать всё
```

### Сетевые хранилища

Отдельного клиента для NAS нет и не нужно — примонтируйте и укажите путь:

```bash
mount -t cifs //nas/movies /mnt/movies -o user=...        # SMB
mount -t nfs  nas:/movies  /mnt/movies                    # NFS
rclone mount mydrive:Movies /mnt/movies --vfs-cache-mode full   # WebDAV, облака
```

## Доступ

`ACCESS_CODE` — общий код входа. Каждый, кто его вводит, заводит себе профиль с
именем; история просмотра и списки у всех свои. Сессия живёт полгода, чтобы
телевизор не спрашивал код каждую неделю.

Пустой `ACCESS_CODE` делает сайт открытым для всех, кто до него дотянется.
Оставляйте пустым только в домашней сети.

## Что уже сделано

- Каталог: главная с подборками, жанры, фильтры, поиск по всему TMDB
- Своя библиотека: индексация, обложки, качество, дорожки, субтитры
- Плеер: перемотка пультом, дорожки, субтитры, докрутка с места остановки
- «Продолжить просмотр» и «Буду смотреть» — на профиль
- Сериалы: сезоны, серии, отметка что есть на диске
- Скачивание любого своего файла одной кнопкой
- Русский и английский интерфейс
- PWA: ставится на домашний экран, оболочка и обложки работают офлайн

## Разработка

```bash
npm run dev          # сервер :8080 и Vite :5173 одновременно
npm run dev:server
npm run dev:web
```

Клиент в dev-режиме проксирует `/api` на сервер, так что работать можно с
`http://localhost:5173`.

### Структура

```
server/src
  metadata/tmdb.js     клиент TMDB: запросы, кэш, нормализация, ru-фолбэк
  sources/local.js     индексатор и стример вашей библиотеки
  sources/registry.js  интерфейс источников
  media/probe.js       разбор имён файлов и ffprobe
  routes/              catalog, titles, playback, user, auth, images
web/src
  nav/                 навигация пультом: фокус, клавиши, D-pad
  device/              определение устройства и класса производительности
  components/          Row, Card, Hero, Image — всё с учётом ТВ
  pages/               Home, Title, Player, Search, Browse, Library, Settings
```

## Стек

Node + Express на сервере, React + Vite на клиенте. Без базы данных: состояние
лежит в JSON с атомарной записью — для личного кинотеатра этого достаточно, а
падать нечему. Клиент собирается под Chromium 61+, чтобы открываться на
телевизорах 2017 года.
