# Frontend Rules
- Mobile-first responsive design (min-width media queries)
- Dark theme by default (#0f0f0f background, #e8ff59 accent — ugcgo brand)
- No external CDN dependencies in production HTML (self-contained)
- Semantic HTML5 elements
- Accessibility: alt tags, aria labels, keyboard navigation
- Performance: lazy load images, minimize DOM nodes
